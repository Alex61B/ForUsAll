⏺ All 114 specs pass. The fix is clean.

  The root cause was _request_row.html.erb naming its local variable request,
  which shadowed Rails' ActionDispatch::Request helper in the view context.
  Rails 8 uses that request method internally when resolving URL helpers — when
  the partial overwrote it with a TimeOffRequest object, the routing/URL helper
  calls in the surrounding template could fail silently, causing the response to
   be truncated before the filter form rendered.

  Fix: renamed request → tor in _request_row.html.erb and updated the render
  call in index.html.erb to match. All 114 specs still pass.
